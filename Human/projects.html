PROJECT_02

Artemis (Aerial Drone)

Artemis is a project I worked on during my second year of engineering school. The goal was to build a flying quadcopter, and I was responsible for the embedded systems. I set up the STM32 environment for the team and developed the PWM motor control driver, the 9-axis IMU driver and its calibration, as well as drivers for the GPS and LiDAR sensors. I also implemented a basic feedback control loop using control theory for stabilization. This was one of my favorite technical projects. It was challenging, especially as my first experience working on a complex project with other engineers. Due to time constraints, the drone could only hover in stable conditions without wind.

C/C++ Embedded System STM32 Control Theory

PROJECT_03

Axolotl (Processor Suite project)

Axolotl is a project composed of several sub-projects. First, I developed a simple CPU in VHDL to deepen my understanding of VHDL and digital simulation, with its own instruction set and ABI. I then designed an assembly language for the processor and developed a translator to convert assembly code into binary. Finally, I developed an emulator capable of running these binaries by emulating the processor and memory. The next steps are to complete the memory management and implement the processor on an FPGA, with a mechanism to load code onto it.

PROJECT_04

SecureFileBackupProtocol

SecureFileBackupProtocol is a project I developed during my studies at the IUT of Montpellier-Sète. The goal was to design a secure and efficient client-server backup system. I developed the protocol to support file and recursive folder backups and restoration, with secure communication using TLS 1.3. I also implemented AES-256 encryption with authentication tags for server-side storage, as well as key generation from a passphrase. The project also includes deletion, installation scripts, and an optimization to avoid backing up files that have not been modified. This project can also be coupled with ubuntu backup to boost recurrency This project gave me a deeper understanding of network protocols, cryptography, secure storage, and the complexity of designing a reliable backup system.

PROJECT_05

AIGomoku

This project is an implementation of the Gomoku game, featuring a graphical interface and an AI opponent based on the Minimax algorithm. I implemented several optimizations to explore the game tree more deeply, including Negamax, Zobrist hashing with transposition tables, and move pruning based on board proximity: positions that have no nearby stones are excluded from the search tree, significantly reducing the number of unnecessary nodes. The next step is to implement an evolutionary approach, where multiple AIs play against each other, the best-performing ones are selected, and their evaluation function parameters are mutated over several generations to progressively create a stronger AI.
